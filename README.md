# MathReformationWebsite

## Overview
This repository is a Python Flask web application designed to interface with a MySQL database using SQL-Alchemy.

Check out this website (Hosted by PythonAnywhere) at (https://www.mathreformation.com)

Primary Tools Used:
* Flask
* Elasticsearch
* Bootstrap

Features:
* Authentication
* Elasticsearch Engine
* HTML/Markdown Editor
* Dark Mode
